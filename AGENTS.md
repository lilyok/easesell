# EaseSell

This repository is a SwiftUI iPhone app. The Xcode project is `ios/EaseSell.xcodeproj`.

Open that project in Xcode and run it on an iPhone. Photos, drafts, the weekly Vision lookup count, and the Google Cloud Vision key stay on the phone. Listings are unlimited. Two Vision lookups each week are free. After that, new listings stay blank for manual entry, and Suggest details opens the subscription sheet.
